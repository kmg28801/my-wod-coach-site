# My WOD Coach — 공개 사이트

매일의 무료 크로스핏 WOD를 발행합니다. **이 저장소의 HTML은 손으로 고치지 않습니다** —
앱 저장소에서 생성해 덮어씁니다.

## 생성·발행

앱 저장소(`my-wod-coach`)에서:

```bash
npm run publish:web        # site/ 재생성 (기본 2주치)
npm run publish:web -- 4   # 4주치
```

그 뒤 `site/` 내용을 이 저장소 루트로 복사해 커밋·푸시하면 GitHub Pages가 배포합니다.

## 왜 있나

App Store 노출을 늘리기 위해서다. Apple 정의상 **웹 리퍼러로 들어온 트래픽은 제품 페이지
조회로 직접 계상**되고, 날짜별 WOD 페이지는 `오늘의 와드`·`EMOM 와드` 같은 롱테일 쿼리를
잡는다. 새 콘텐츠를 쓰는 게 아니라 앱이 이미 매주 생성하는 것을 한 번 더 뿌리는 구조다.

⚠️ 색인·순위에 4~8주 걸린다. 즉시 효과를 기대하지 말 것.

배경: 앱 저장소 `docs/release/impressions-plan-2026-09-27.md`
